# CareEcho

A patient AI companion for people with dementia. It answers repeated questions calmly and correctly, using only memories a caregiver has confirmed.

Built at Hack Knight Fall 2026.

## Structure

- `backend/`: FastAPI API (memories, extraction, alerts, family messages)
- `frontend/`: React app (caregiver app, patient day clock, dashboard)
- `docs/`: pitch, architecture, Devpost drafts
